# Bio-shop Bot v54.8

ระบบ Telegram Bot สำหรับสร้างไฟล์ VPN พร้อมเว็บไซต์ควบคุม โดยบอทและเว็บไซต์ใช้ฐานข้อมูล SQLite เดียวกันแบบเรียลไทม์

## ความสามารถล่าสุด

- เว็บไซต์ควบคุมผ่าน URL, IP หรือโดเมน
- จัดการเครือข่ายและแพ็กเกจจากเว็บไซต์
- แยกประเภทเครือข่ายเป็น:
  - **สินค้าเครือข่าย VPN ซื้อ** สำหรับเมนูซื้อ VPN
  - **สินค้าเครือข่าย VPN ทดลอง** สำหรับเมนูทดลองใช้ฟรี
- บอทจะแสดงเฉพาะเครือข่ายที่ตรงกับเมนูที่ใช้งาน
- เพิ่ม แก้ไข ลบ และเปิด–ปิดแพ็กเกจได้
- กำหนด Inbound ID แยกในแต่ละแพ็กเกจ
- กำหนดรายละเอียดแพ็กเกจและแสดงให้ลูกค้าดูก่อนตั้งชื่อไฟล์
- เว็บไซต์และบอทอ่านข้อมูลจากฐานข้อมูลเดียวกันทันที

## ลำดับการซื้อ VPN

```text
เลือกเครือข่ายสินค้า
→ เลือกแพ็กเกจ
→ แสดงชื่อแพ็กเกจ ราคา และรายละเอียด
→ ตั้งชื่อไฟล์
→ ระบุจำนวนวัน
→ กำหนด GB ตามเงื่อนไขแพ็กเกจ
→ สร้างไฟล์และส่งไปยัง DM
```

หลังเลือกรายการแพ็กเกจ ลูกค้าจะเห็นข้อมูลในรูปแบบใกล้เคียงนี้:

```text
✅ เครือข่าย: AIS
📦 แพ็กเกจ: AISPLAY
💳 ราคา: 3 เครดิต/วัน
📝 รายละเอียด:
ใช้งาน AISPLAY พร้อมโควตาตามแพ็กเกจ
```

ก่อนสร้างไฟล์ ระบบจะแสดงสรุปข้อมูลแบบเต็มเพื่อให้ตรวจสอบอีกครั้ง:

```text
📋 กรุณาตรวจสอบข้อมูลก่อนสร้าง

🌐 เครือข่าย: AIS
📦 แพ็กเกจ: AISPLAY
📌 ชื่อไฟล์: t
📅 จำนวนวัน: 2 วัน
💾 GB: 10
💳 ราคา: 6.00 เครดิต

ยืนยันการสร้างไฟล์หรือไม่?
```

## เงื่อนไข GB ของแพ็กเกจ

### 1. กำหนดจำนวน GB

ในหน้าแก้ไขแพ็กเกจ ให้เลือกตัวเลือก **กำหนดจำนวน GB** แล้วระบุค่า GB มากกว่า 0 ระบบจะใช้ค่านั้นทันทีและไม่ถามลูกค้าเรื่อง GB ซ้ำ เช่น:

```text
แพ็กเกจนี้กำหนดโควตา 5 GB
ระบบจะใช้ค่านี้โดยไม่ถามซ้ำ
```

ในกรณีนี้จะไม่ใช้ค่า **GB สูงสุดที่ผู้ใช้ใส่ได้**

### 2. ให้ผู้ใช้กำหนด

ในหน้าแก้ไขแพ็กเกจ ให้เลือกตัวเลือก **ให้ผู้ใช้กำหนด** แล้วระบุ **GB สูงสุดที่ผู้ใช้ตั้งได้** หากมากกว่า `0` ระบบจะแจ้งเฉพาะเพดาน เช่น:

```text
กรุณาระบุ GB ที่ต้องการใช้สำหรับทดลอง (สูงสุด 5 GB):
```

จะไม่แสดงคำว่า “หากไม่จำกัดพิมพ์ 0” เพราะมีเพดานบังคับอยู่แล้ว

### 3. ให้ผู้ใช้กำหนดโดยไม่จำกัด

ในโหมด **ให้ผู้ใช้กำหนด** หาก **GB สูงสุด = 0** ระบบจะแจ้ง:

```text
กรุณาระบุ GB ที่ต้องการใช้สำหรับทดลอง:
หากไม่จำกัดพิมพ์ 0
```

หากกรอกเกินเพดาน ระบบจะแจ้งช่วงค่าที่ถูกต้องและจะไม่สร้างไฟล์จนกว่าจะกรอกใหม่

## การทดลองใช้ฟรี

- ใช้เฉพาะเครือข่ายประเภท **เครือข่าย VPN ทดลองใช้งาน**
- รองรับการกำหนดแพ็กเกจทดลองและ Inbound ID
- รองรับโหมดรีเซ็ตสิทธิ์:
  - รีเซ็ตเวลา 00:00 พร้อมกันทุกคน
  - รีเซ็ตตามเวลาที่แต่ละคนเริ่มใช้งาน
- รองรับช่องทาง DM, กลุ่ม, กลุ่มที่กำหนด และรูปแบบผสม
- จำกัดสิทธิ์ทดลองเป็นจำนวนครั้งต่อคน

## การแก้ไขแพ็กเกจและรายละเอียด

- รายละเอียดแพ็กเกจรองรับข้อความหลายบรรทัดและแสดงพื้นที่แก้ไขขนาดใหญ่ขึ้น
- ตัวเลือก GB เป็นปุ่มเลือก 2 โหมดที่ไม่ใช้ค่าทับซ้อนกัน
- โหมดกำหนดจำนวน GB จะซ่อนช่อง GB สูงสุด
- โหมดให้ผู้ใช้กำหนดจะซ่อนช่อง GB ตายตัวและแสดงช่อง GB สูงสุด
- ระบบ API ตรวจสอบโหมดซ้ำอีกชั้นเพื่อป้องกันค่าผิดจากไคลเอนต์อื่น

## รายละเอียดการยกเลิกและข้อความระหว่างซื้อ

ระหว่างขั้นตอนตั้งชื่อไฟล์ ระบบจะแจ้งข้อความยกเลิกและแสดงปุ่มยกเลิกให้ลูกค้าเห็น

ค่าเริ่มต้น **หน่วงปุ่มยกเลิก** คือ `1 วินาที` และปรับได้จากเว็บไซต์ โดยค่าหน่วงมีผลเฉพาะเวลาส่งปุ่มยกเลิก ไม่หน่วงคำถามหรือการทำงานของบริการ

เมื่อบอทถามข้อมูลที่ต้องพิมพ์ ระบบจะใช้ Telegram **ForceReply** และผูกคำตอบกับข้อความคำถามล่าสุดทั้งใน DM และกลุ่ม เพื่อให้ตอบกลับได้สม่ำเสมอจากทุกอุปกรณ์

หลังตรวจสอบข้อมูลและกด **ยืนยันการสร้าง** ระบบจะแก้ไขข้อความตรวจสอบเดิมให้เหลือสถานะการกระทำที่เลือก พร้อมสถานะการสร้าง/ส่งไปยัง DM โดยไม่ทิ้งปุ่มยืนยันหรือยกเลิกไว้ซ้ำซ้อน หากกด **ยกเลิก** ข้อความเดิมจะถูกแทนที่ด้วยสถานะยกเลิกทันที

ปุ่มยืนยันใช้ข้อความ **✅ ยืนยันการสร้าง** และปุ่มยกเลิกใช้ข้อความ **❌ ยกเลิก** ให้ตรงกันทั้งการซื้อ VPN และทดลองใช้ฟรี



## การอัปเดตค่าและการซิงก์ฐานข้อมูล

การบันทึกค่าจากเว็บไซต์จะถูกเขียนลงฐานข้อมูลทันที หลังบันทึกระบบจะซิงก์ข้อมูลไปยัง Google Sheet ที่เลือกไว้โดยอัตโนมัติเมื่อใช้ Google Sheet เป็นปลายทาง นอกจากนี้ยังมีปุ่ม **ซิงก์ข้อมูล** ในหน้า **ฐานข้อมูล** สำหรับสั่งซิงก์ทันที

ระบบตรวจสอบและปรับเส้นทางการบันทึกสำหรับค่าตั้งค่า เครือข่าย แพ็กเกจ ผู้ใช้ เครดิต โค้ดเครดิต และการนำเข้าฐานข้อมูลให้ใช้ฐานข้อมูลชุดเดียวกัน

## การเปลี่ยนฐานข้อมูล

ในเมนู **ฐานข้อมูล** มีปุ่ม **เปลี่ยนฐานข้อมูล** ให้เลือก **ในระบบ (SQLite)** หรือ **Google Sheet** โดยค่าเริ่มต้นคือในระบบ

เมื่อกด **ตกลงและรีเซ็ตข้อมูล** ระบบจะตรวจสอบค่าที่จำเป็นก่อน แล้วรีเซ็ตข้อมูลปัจจุบันทั้งหมด หลังจากนั้นให้อัปโหลดไฟล์ `.db` ผ่านเมนูนำเข้า ระบบจะนำข้อมูลไปใส่ฐานข้อมูลที่เลือกไว้

สำหรับ Google Sheet สามารถกรอกค่าในเว็บไซต์ได้โดยตรง:

- Google Sheet ID
- คำนำหน้าชีต
- Google Service Account JSON

หรือกำหนด `GOOGLE_SERVICE_ACCOUNT_JSON` ผ่าน Environment Variables ก็ได้ จากนั้นแชร์ Google Sheet ให้ Service Account มีสิทธิ์ Editor ระบบจะแยกข้อมูลแต่ละตารางเป็นชีต เช่น `users`, `clients`, `settings`, `networks`, `network_packages` และ `buy_log` ซึ่งสามารถเปิดดู แก้ไข ลบแถว แก้หัวตาราง และจัดการข้อมูลต่อใน Google Sheets ได้

การเปลี่ยนฐานข้อมูลและการนำเข้าแบบ Google Sheet ใช้แพ็กเกจ `gspread` และ `google-auth`

## จัดการข้อมูลจากเว็บไซต์

เว็บไซต์รองรับ:

- ภาพรวมระบบ
- ตั้งค่าบอท
- จัดการเครือข่ายและแพ็กเกจ
- ผู้ใช้และเครดิต
- รายการสั่งซื้อ
- ประวัติการแก้ไข
- ฐานข้อมูล
- สำรอง/คืนค่าข้อมูล
- จัดการบัญชีเว็บไซต์

## การสำรองและคืนค่าฐานข้อมูล

- ดาวน์โหลดฐานข้อมูล SQLite
- อัปโหลดไฟล์สำรอง
- เลือกแทนที่ข้อมูลทั้งหมดหรือรวมกับข้อมูลเดิม
- ระบบตรวจสอบไฟล์ก่อนนำเข้า

## Environment variables

### จำเป็น

| ตัวแปร | รายละเอียด |
|---|---|
| `BOT_TOKEN` | Token ของ Telegram Bot |
| `ADMIN_IDS` | Telegram User ID ของผู้ดูแล คั่นด้วย comma |
| `XUI_URL` | URL ของ 3x-ui Panel |
| `XUI_API_TOKEN` | API Token ของ 3x-ui หากใช้งาน |
| `XUI_USERNAME` | Username ของ 3x-ui เมื่อไม่ใช้ API Token |
| `XUI_PASSWORD` | Password ของ 3x-ui เมื่อไม่ใช้ API Token |
| `WEB_ADMIN_PASSWORD` | รหัสผ่านเว็บไซต์จัดการ |
| `WEB_ADMIN_SECRET` | Secret สำหรับเซสชันเว็บไซต์ อย่างน้อย 32 ตัวอักษร |

### ตัวเลือก

| ตัวแปร | รายละเอียด |
|---|---|
| `DB_PATH` | ตำแหน่งฐานข้อมูล SQLite ค่าแนะนำ `/data/bot.db` |
| `WEB_ADMIN_ENABLED` | เปิดหรือปิดเว็บไซต์จัดการ |
| `WEB_ADMIN_USERNAME` | ชื่อผู้ใช้เว็บไซต์ |
| `WEB_HOST` | Host ของเว็บเซิร์ฟเวอร์ |
| `PORT` | Port ของเว็บเซิร์ฟเวอร์ |
| `PUBLIC_URL` | URL เว็บไซต์ที่ใช้แสดงในบอท |
| `WEB_COOKIE_SECURE` | ใช้ Secure Cookie เมื่อเป็น HTTPS |
| `TRUEMONEY_WALLET_PHONE` | เบอร์รับซอง TrueMoney |

ดูรายการตัวแปรทั้งหมดได้ที่ `env.example`

## การ Deploy บน Railway

1. อัปโหลดไฟล์ทั้งหมดไว้ที่ root ของ Repository
2. ตั้ง Environment variables
3. ใช้ Start Command:

```text
python main.py
```

4. ใช้ Dockerfile ที่อยู่ใน root
5. ผูก Volume ที่ `/data` เพื่อเก็บฐานข้อมูลถาวร
6. Health check ใช้ `/health`

ไม่ใช้ `uvicorn main:app` เพราะ `main.py` เป็นตัวเริ่มทั้ง Telegram Bot และเว็บไซต์

## รันบนเครื่องหรือ VPS

```bash
python -m pip install -r requirements.txt
python main.py
```
