# Bio-shop Bot v54.0

ระบบ Telegram Bot สำหรับสร้างไฟล์ VPN พร้อมเว็บไซต์ควบคุม โดยบอทและเว็บไซต์ใช้ฐานข้อมูล SQLite เดียวกันแบบเรียลไทม์

## ความสามารถล่าสุด

- เว็บไซต์ควบคุมผ่าน URL, IP หรือโดเมน
- จัดการเครือข่ายและแพ็กเกจจากเว็บไซต์
- แยกประเภทเครือข่ายเป็น:
  - **เครือข่ายสินค้า** สำหรับเมนูซื้อ VPN
  - **เครือข่าย VPN ทดลองใช้งาน** สำหรับเมนูทดลองใช้ฟรี
- บอทจะแสดงเฉพาะเครือข่ายที่ตรงกับเมนูที่ใช้งาน
- เพิ่ม แก้ไข ลบ และเปิด–ปิดแพ็กเกจได้
- กำหนด Inbound ID แยกในแต่ละแพ็กเกจ
- กำหนดรายละเอียดแพ็กเกจและแสดงให้ลูกค้าดูก่อนตั้งชื่อไฟล์
- เว็บไซต์และบอทอ่านข้อมูลจากฐานข้อมูลเดียวกันทันที

## ลำดับการซื้อ VPN

```text
เลือกเครือข่ายสินค้า
→ เลือกแพ็กเกจ
→ แสดงชื่อแพ็กเกจ ราคา และรายละเอียด
→ ตั้งชื่อไฟล์
→ ระบุจำนวนวัน
→ กำหนด GB ตามเงื่อนไขแพ็กเกจ
→ สร้างไฟล์และส่งไปยัง DM
```

หลังเลือกรายการแพ็กเกจ ลูกค้าจะเห็นข้อมูลในรูปแบบใกล้เคียงนี้:

```text
✅ เครือข่าย: AIS
📦 แพ็กเกจ: AISPLAY
💳 ราคา: 5 เครดิต/วัน
📝 รายละเอียด: รายละเอียดของแพ็กเกจ
```

## เงื่อนไข GB ของแพ็กเกจ

### 1. กำหนด GB ตายตัว

ถ้า **GB ที่กำหนด** มากกว่า `0` ระบบจะใช้ค่านั้นทันทีและไม่ถามลูกค้าเรื่อง GB ซ้ำ เช่น:

```text
แพ็กเกจนี้กำหนดโควตา 5 GB
ระบบจะใช้ค่านี้โดยไม่ถามซ้ำ
```

ในกรณีนี้จะไม่ใช้ค่า **GB สูงสุดที่ผู้ใช้ใส่ได้**

### 2. ให้ลูกค้ากำหนด GB เองโดยมีเพดาน

ถ้า **GB ที่กำหนด = 0** และตั้งค่า GB สูงสุดมากกว่า `0` ระบบจะแจ้งเฉพาะเพดาน เช่น:

```text
กรุณาระบุ GB ที่ต้องการใช้สำหรับทดลอง (สูงสุด 5 GB):
```

จะไม่แสดงคำว่า “หากไม่จำกัดพิมพ์ 0” เพราะมีเพดานบังคับอยู่แล้ว

### 3. ให้ลูกค้ากำหนด GB เองโดยไม่มีเพดาน

ถ้า **GB ที่กำหนด = 0** และ **GB สูงสุด = 0** ระบบจะแจ้ง:

```text
กรุณาระบุ GB ที่ต้องการใช้สำหรับทดลอง:
หากไม่จำกัดพิมพ์ 0
```

หากกรอกเกินเพดาน ระบบจะแจ้งช่วงค่าที่ถูกต้องและจะไม่สร้างไฟล์จนกว่าจะกรอกใหม่

## การทดลองใช้ฟรี

- ใช้เฉพาะเครือข่ายประเภท **เครือข่าย VPN ทดลองใช้งาน**
- รองรับการกำหนดแพ็กเกจทดลองและ Inbound ID
- รองรับโหมดรีเซ็ตสิทธิ์:
  - รีเซ็ตเวลา 00:00 พร้อมกันทุกคน
  - รีเซ็ตตามเวลาที่แต่ละคนเริ่มใช้งาน
- รองรับช่องทาง DM, กลุ่ม, กลุ่มที่กำหนด และรูปแบบผสม
- จำกัดสิทธิ์ทดลองเป็นจำนวนครั้งต่อคน

## รายละเอียดการยกเลิกและข้อความระหว่างซื้อ

ระหว่างขั้นตอนตั้งชื่อไฟล์ ระบบจะแจ้งข้อความยกเลิกและแสดงปุ่มยกเลิกให้ลูกค้าเห็น

ค่าเริ่มต้น **หน่วงปุ่มยกเลิก** คือ `2 วินาที` และปรับได้จากเว็บไซต์

## จัดการข้อมูลจากเว็บไซต์

เว็บไซต์รองรับ:

- ภาพรวมระบบ
- ตั้งค่าบอท
- จัดการเครือข่ายและแพ็กเกจ
- ผู้ใช้และเครดิต
- รายการสั่งซื้อ
- ประวัติการแก้ไข
- ฐานข้อมูล
- สำรอง/คืนค่าข้อมูล
- จัดการบัญชีเว็บไซต์

## การสำรองและคืนค่าฐานข้อมูล

- ดาวน์โหลดฐานข้อมูล SQLite
- อัปโหลดไฟล์สำรอง
- เลือกแทนที่ข้อมูลทั้งหมดหรือรวมกับข้อมูลเดิม
- ระบบตรวจสอบไฟล์ก่อนนำเข้า

## Environment variables

### จำเป็น

| ตัวแปร | รายละเอียด |
|---|---|
| `BOT_TOKEN` | Token ของ Telegram Bot |
| `ADMIN_IDS` | Telegram User ID ของผู้ดูแล คั่นด้วย comma |
| `XUI_URL` | URL ของ 3x-ui Panel |
| `XUI_API_TOKEN` | API Token ของ 3x-ui หากใช้งาน |
| `XUI_USERNAME` | Username ของ 3x-ui เมื่อไม่ใช้ API Token |
| `XUI_PASSWORD` | Password ของ 3x-ui เมื่อไม่ใช้ API Token |
| `WEB_ADMIN_PASSWORD` | รหัสผ่านเว็บไซต์จัดการ |
| `WEB_ADMIN_SECRET` | Secret สำหรับเซสชันเว็บไซต์ อย่างน้อย 32 ตัวอักษร |

### ตัวเลือก

| ตัวแปร | รายละเอียด |
|---|---|
| `DB_PATH` | ตำแหน่งฐานข้อมูล SQLite ค่าแนะนำ `/data/bot.db` |
| `WEB_ADMIN_ENABLED` | เปิดหรือปิดเว็บไซต์จัดการ |
| `WEB_ADMIN_USERNAME` | ชื่อผู้ใช้เว็บไซต์ |
| `WEB_HOST` | Host ของเว็บเซิร์ฟเวอร์ |
| `PORT` | Port ของเว็บเซิร์ฟเวอร์ |
| `PUBLIC_URL` | URL เว็บไซต์ที่ใช้แสดงในบอท |
| `WEB_COOKIE_SECURE` | ใช้ Secure Cookie เมื่อเป็น HTTPS |
| `TRUEMONEY_WALLET_PHONE` | เบอร์รับซอง TrueMoney |

ดูรายการตัวแปรทั้งหมดได้ที่ `env.example`

## การ Deploy บน Railway

1. อัปโหลดไฟล์ทั้งหมดไว้ที่ root ของ Repository
2. ตั้ง Environment variables
3. ใช้ Start Command:

```text
python main.py
```

4. ใช้ Dockerfile ที่อยู่ใน root
5. ผูก Volume ที่ `/data` เพื่อเก็บฐานข้อมูลถาวร
6. Health check ใช้ `/health`

ไม่ใช้ `uvicorn main:app` เพราะ `main.py` เป็นตัวเริ่มทั้ง Telegram Bot และเว็บไซต์

## รันบนเครื่องหรือ VPS

```bash
python -m pip install -r requirements.txt
python main.py
```
